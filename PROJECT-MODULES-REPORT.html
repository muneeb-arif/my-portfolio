1. Architecture overview

The repository is a two-part application:

  • Root package (package.json): Create React App (react-scripts) single-page app. Source lives under src/. It talks to the backend via REACT_APP_API_URL (see src/utils/apiConfig.js).
  • API package (standalone-api/package.json): Next.js 14 project used primarily as an HTTP API. Routes are implemented under standalone-api/src/app/api/ and dispatched through a generated catch-all route standalone-api/src/app/api/[[...slug]]/route.ts plus standalone-api/src/lib/api-router.generated.ts (regenerated by standalone-api/scripts/generate-api-router.mjs on prebuild).
Implication: “Full Next.js” migration would merge these two packages so pages and /api/* ship from one Next app; today they are intentionally separated for CRA + API hosting (e.g. Vercel with SPA rewrites for the frontend).

4. Public portfolio site (features & UI)

Rendered by AppContent in src/App.js when the route is the main site (not dashboard/signup-only routes).

4.1 Data loading & UX

  • Settings-first load: SettingsProvider / useSettings loads site configuration before portfolio data.
  • Portfolio data: portfolioService.getPublishedProjects(), getCategories(), category filtering via getPublishedProjectsByCategory with client-side fallback.
  • Loaders: RainLoader for initial settings load; additionalDataLoading drives header/section loading hints.
  • Environment guard: checkEnvMissing() from src/config/env.js + warning Toast if API URL missing.
  • Meta tags: DynamicHead + metaTagService.updateMetaTags(settings) after settings load.
  • Toasts: ToastContainer, Toast, toastService.

7. API server (Next.js)

7.1 Request dispatch

  • Catch-all route: standalone-api/src/app/api/[[...slug]]/route.ts exports GET, POST, PUT, PATCH, DELETE, OPTIONS.
  • dispatchApi in standalone-api/src/lib/api-router.generated.ts matches path segments to a handler module and HTTP method name (e.g. GET, POST).
  • Regeneration: npm run prebuild in standalone-api/ runs standalone-api/scripts/generate-api-router.mjs.
